CYBERGUARD Quizy

Panoul nu este activat pe acest server

Panoul se activează cu o parolă setată pe server (variabila ADMIN_PASSWORD). Scriptul de instalare o generează automat; o vezi pe server cu comanda de mai jos.

sudo cat /etc/quizy/env

Panou de administrare

Administratorul serverului lasă câmpul gol sau scrie „admin”.

Conturi de organizator

Fiecare organizator intră cu propriul cont și vede doar evenimentele lui. Tu vezi lista tuturor evenimentelor, dar nu le poți deschide pe ale altora.

Schimbă parola

Dacă debifezi, doar cine are cont în acest panou poate crea evenimente noi (recomandat).

Ștergerea automată a datelor

zile

0 = nu se șterg automat. Se numără de când evenimentul e marcat „închis” din pagina lui de administrare; se șterge tot: întrebări, răspunsuri, certificate. Descarcă raportul înainte.
